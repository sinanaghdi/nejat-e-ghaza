The repository connector available in this session can read the repository and commit files, but does not expose a repository-settings write action for the About description/topics. Apply these values manually in GitHub → Repository → About → Edit repository details.

Real product screenshots should be captured from a tested deployment and committed under docs/screenshots/; do not use illustrative mockups as if they were screenshots of the running app.
