# Nejat-e-Ghaza Frontend

React + TypeScript + Vite frontend foundation.

## Development

From the repository root:

    cd frontend
    npm install
    npm run dev

The current home page uses mock offer data. API integration is intentionally the next step.

## Planned structure

- Authentication
- Offer discovery
- Offer details
- Cart and checkout
- Customer orders
